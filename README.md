# Facebook Page AI Automation 🚀

একটি শক্তিশালী ও স্বয়ংক্রিয় ফেসবুক পেজ ম্যানেজমেন্ট প্ল্যাটফর্ম যা Google Gemini AI এবং Telegram Bot দিয়ে পরিচালিত।

## 🌟 মূল বৈশিষ্ট্যসমূহ

1. **ইউটিউব ভিডিও ট্র্যাকার ও ট্রান্সক্রিপ্ট এআই:** নির্দিষ্ট ইউটিউব চ্যানেলে নতুন ভিডিও আপলোড হলে স্বয়ংক্রিয়ভাবে ভিডিওর অডিও/সাবটাইটেল বিশ্লেষণ করে ভাইরাল ফেসবুক পোস্ট ড্রাফট তৈরি করে।
2. **টেলিগ্রাম ওয়ান-ক্লিক অ্যাপ্রুভাল:** পোস্ট সরাসরি ফেসবুকে যাওয়ার আগে আপনার ফোনে টেলিগ্রাম বটে প্রিভিউ সহ আসে। আপনি শুধু বাটন চেপে `[Approve & Publish]`, `[Regenerate]` বা `[Cancel]` করতে পারেন।
3. **অন-ডিমান্ড পোস্ট জেনারেশন:** যেকোনো ইউটিউব ভিডিওর লিংক টেলিগ্রাম বটে পেস্ট করলে তৎক্ষণাৎ পোস্ট বানিয়ে দেয়।
4. **স্মার্ট মেসেঞ্জার অটো-রিপ্লাই:** গ্রাহকদের যেকোনো প্রশ্নের উত্তর `knowledge_base.json` থেকে তথ্য জেনে সাবলীল ও বিনয়ী বাংলায় দিয়ে থাকে।
5. **কমেন্ট অটো-রিপ্লাই ও প্রাইভেট ইনবক্স:** পোস্টের কমেন্টে উত্তর দেওয়া ছাড়াও দাম/বিস্তারিত জানতে চাইলে ফেসবুকের নিয়ম মেনে স্বয়ংক্রিয়ভাবে ইনবক্স মেসেজ পাঠায়।
6. **জরুরি অ্যাডমিন এলার্ট:** অচেনা প্রশ্ন বা গ্রাহক অসন্তুষ্ট হলে টেলিগ্রামে অ্যাডমিনকে তৎক্ষণাৎ নোটিফিকেশন পাঠায়।
7. **২৪/৭ ক্লাউড ফ্রেন্ডলি:** Docker, Render.com, Railway বা যেকোনো VPS-এ পিসি বা ফোন বন্ধ থাকলেও ২৪ ঘণ্টা একটানা চলতে সক্ষম।

```
d:\TOOL\

├── main.py                   # FastAPI সার্ভার, টেলিগ্রাম পোলিং ও শিডিউলার
├── requirements.txt          # লাইব্রেরি ডিপেনডেন্সি তালিকা
├── Dockerfile                # ২৪/৭ ডকার কন্টেইনার ফাইল
├── docker-compose.yml        # ডকার কম্পোজ কনফিগারেশন
├── render.yaml               # Render.com এ ১-ক্লিক ডিপ্লয়মেন্ট ব্লুপ্রিন্ট
├── SETUP_GUIDE_BN.md         # সম্পূর্ণ বাংলায় ধাপে ধাপে সেটআপ গাইড
├── routes/
│   └── webhook.py            # মেটা ফেসবুক ওয়েব-হুক ভেরিফিকেশন ও ইভেন্ট হ্যান্ডলার
├── services/
│   ├── gemini_service.py     # জেমিনি এআই পোস্ট রাইটার ও চ্যাটবট লজিক
│   ├── youtube_service.py    # ইউটিউব চ্যানেল মনিটর ও ট্রান্সক্রিপ্ট এক্সট্র্যাক্টর
│   ├── telegram_service.py   # টেলিগ্রাম বট, ইনলাইন বাটন ও নোটিফিকেশন
│   └── facebook_service.py   # মেটা গ্রাফ এপিআই (পোস্ট, কমেন্ট, ইনবক্স)
└── tests/
    └── test_services.py      # অটোমেটেড ইউনিট টেস্ট
```

## 🚀 দ্রুত লোকাল রান করার উপায়

১. ভার্চুয়াল এনভায়রনমেন্ট সক্রিয় করুন:
```bash
venv\Scripts\activate
```

২. `.env` ফাইলে আপনার API কী এবং টোকেন বসান:
```bash
copy .env.example .env
```

৩. সার্ভার চালু করুন:
```bash
python main.py
```

সার্ভার চালু হলে ব্রাউজারে `http://localhost:8000` এ গিয়ে ড্যাশবোর্ড স্ট্যাটাস দেখতে পারবেন।
